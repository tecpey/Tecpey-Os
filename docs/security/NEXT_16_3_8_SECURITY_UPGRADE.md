# Next.js 16.3.8 security upgrade

This change upgrades the direct, exact Next.js dependency from `16.3.3` to `16.3.8` and regenerates `package-lock.json` with npm 10 from the public npm registry.

## Security reason

The exact-head Container Supply Chain scan rejected Next.js `16.3.3` for `GHSA-vcvr-r3jv-pc5j` (critical remote code execution in `next/og` `ImageResponse`). The scanner reported the minimum fixed version as `16.3.6`. The Next.js security release published on 2026-09-30 recommends `16.3.8` for the active 16.3 line, so this remediation moves to that current security patch rather than stopping at the minimum fixed release.

## Integrity constraints

- The dependency remains exact-version pinned.
- The lockfile was generated by npm 10; integrity hashes were not edited manually.
- No vulnerability ignore, scanner exception, `|| true`, or severity downgrade is introduced.
- This change does not authorize deployment or change launch-governance decisions.
